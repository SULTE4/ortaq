Libre Franklin — Impallari Type; Source Serif 4 — Adobe.
Downloaded from the official google/fonts repository:
https://github.com/google/fonts/tree/main/ofl/librefranklin
https://github.com/google/fonts/tree/main/ofl/sourceserif4
Both are distributed under SIL Open Font License 1.1. Full licenses accompany the font files.
The files are bundled locally; there are no runtime font CDN requests.

Flutter uses static 400/600/700 Libre Franklin instances and a static 400 Source Serif instance, prepared from the OFL variable sources with fontTools. This avoids selecting the variable font’s default 100 weight in CanvasKit. Copyright notices and the OFL are preserved.
